FR
Le démonstrateur constitue le Point 0 de la méthode Twin:
DATA → BUILD → EVIDENCE → ENGINEERING.

Le Twin reconstruit le contrôle depuis la géométrie Fusion:
41 positions, sonde PA 2D 8×8, wedge 55° SW, sectoriel 35–70°,
skew −10…+10°, 3485 lois focales, scan encodé, cartographie globale,
détection, TFM, voxel, décision, rapport et outputs hardware.

La lecture technicien reprend une convention de sensibilité:
EDM de référence 3 mm = 50% FSH.
La détection aveugle reste indépendante de cette vérité mécanique.

Le rapport est construit en ligne à partir du même contexte Twin.
Le Twin produit aussi les données pour le futur réglage/interface hardware:
positions, orientations, parcours/TOF, sector/skew et délais 64 éléments.

Le Machine Learning n'est pas utilisé pour fabriquer le résultat actuel.
Le Twin crée en revanche le contexte de données nécessaire à un futur ML validé.
